# 动漫人物姿态设计

提供动作线、身体关系、手势、道具与视角的局部参考，供当次主画风技能选择和转译。与 eastern-anime-render 合用时，由它主导整体风格、最终提示词与成图总审阅；本技能不独立定稿、发起生图或作最终通过判断。单独调用时交付姿态参考建议，不据此新增图稿；其他主画风沿用相同分工。静止、悬空、强动态均按当次需要选择，表现力不以动作幅度或结构细描数量衡量。

## 设计与执行

1. 明确动作意图和展示用途：人物在做什么，动作处于哪个瞬间，哪些性格或情绪应可读，以及本次景别要展示什么。依据用户已定方向主动完善，不将普通姿态细节变成问卷。改动作时保留已认可的面容、服装和画法，必要联动按实际调整。
2. 从[姿态方法与参考](references/pose-principles.md)选择有用内容。组织主动作线与身体体块：头、肩、胸廓、骨盆和四肢的方向相互承接；用直曲、收放、前后与留空形成节奏，不把每一关节独立摆成姿势。风、头发、衣摆与身体共同组织当次动势；身体关系需要成立，同时保留服务作品的衣发流动、夸张与留空，由主画风技能统一取舍表现份量。
3. 使手势与持物有明确功能、接触和遮挡。按实际景别处理下肢：地面姿态明确主要支撑与落脚，坐靠等姿态明确承托，悬空姿态让屈伸、前后关系与踝足方向承接躯干动势。艺术简化和遮挡可以成立，未见部位按本次设计合理完善，不冒称来自参考。
4. 用户允许图像参考时，选择适配图片并实际查看，区分完整动作、局部连接、道具接触与构图职责；按需要取局部关系或整体姿势。先决定当次视角，再判断透视和遮挡是否服务展示，不默认低机位、斜构图或全身。图片仅提供所指定关系，人物身份、体型、服装、兵器及整体渲染按用户意图选择。
5. 提供本次有用的动作关系、适用条件及对构图、气质、衣发轮廓的影响，交主画风技能取舍并编写最终提示词，不要求逐关节原样拼入正文。候选图片及职责由主画风技能统一选择，路径文字不等于图像输入；需要原像素裁切时记录来源和像素框，不补画。用户仅文字时按文字方法提供参考，不自动生图或增加动作组及其他景别。
6. 主画风技能需要局部审阅时，按实际景别提供角色意图、连接、接触、遮挡与动作节奏的观察，区分具体结构错误与合理夸张、简化；由主画风技能结合整体表现决定修订。结构正确不等于成图完成，不为证明结构强制露出被衣物遮挡的腿足或关节。文字审阅不能替代成图验证。

## 与其他技能配合

- 使用 eastern-anime-render 时，将姿态建议交回其[入口](../eastern-anime-render/SKILL.md)，由它统一判断动作是否服务本次人物气质、画风与展示目标，选择表现方式，编写最终提示词并完成成图总审阅。体块、承重和接触按需读[人体与手](../eastern-anime-render/references/library/anatomy-hands.md)，不重复渲染或解剖教程。
- 面容需要设计或神态已获认可时，[anime-face-expression](../anime-face-expression/SKILL.md)提供眉眼、视线与嘴部的参考；两类建议均由主画风技能统一协调，不互相主导定稿，改姿势不自动换脸。
- 参考中可见的动作不等于真实武术技法或确定的起跳、落地阶段。可以设计合理的架空动作，但不把设计推断说成已证实的技术。
