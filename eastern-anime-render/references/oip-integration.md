# Open Image Prompts 的可选作用

项目：https://github.com/NanmiCoder/open-image-prompts

它提供可追溯图文案例；当前已检查的检索采用文本与视觉标签，不能将其描述为现成的以图搜图或自动风格提取模型。本 Skill 当前默认核心来自6，0与111只补充相容处理，旧组其余图保留局部参考；数据库只辅助表达和补充对照。

1. 先检查本机是否已有 img-gen-prompts 技能及可用数据，按其真实接口与 status 使用。没有安装时如实报告；当前包不包含该数据库或检索器。
2. 只有用户需要扩展案例时才进行检索。将视觉观察变成查询文本，例如动漫造型、绘画色块、有色轮廓、装饰性插画。这里的词语是查询方向，不是已验证存在的 taxonomy ID。
3. 打开候选图片比较渲染方式；仅题材相同不能判定为风格匹配。
4. 记录真实 ID、来源、匹配依据及缺失特征。准确与相关结果分开；没有结果时不编造来源。
5. 外部案例的提示词不能覆盖用户主体或基础风格规则。原提示词、翻译、重新撰写的提示词保持分离。
6. 保持上游数据库只读。需要保存自己的案例时使用独立本地文件，不写入上游库；不把第三方图片的商业使用权限推定为代码 MIT 授权。

当前状态：未安装或查询 SQLite 数据库。已查阅公开风格卡，并于 2026-10-16 通过浏览器读取用户指定的五个案例提示词、查看各案例首图，不能称为数据库检索或图像相似度搜索。

案例用于局部参考，不覆盖原动漫参考组。可选适配规则见 [按需材质参考](materials.md)，原像素裁切见 [参考映射](reference-map.md)。

补充材质时，以实际表面（如头发、池水、叶片）检索，检查图片而非仅复制标签。记录来源和局部适用范围；不同叶种或水体不得仅凭名称视为同一材质证据。材质词单独输出，不进入核心风格段。

本轮首饰、配饰及补充表面的文字提炼与确切来源见 [分类库来源](library/sources.md) 和 [配饰方法](library/accessories.md)。来源状态逐项区分已读文字、已有视觉观察与本地综合建议；未核验的OIP详情页不当作看图证据。
