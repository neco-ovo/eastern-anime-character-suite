# 从参考图提炼画风并封装 Skill

用途：新增参考组、重新定义画风或审查提炼偏差时读取。普通生图不加载本文件。后续优先复用此流程，无需每次重新观看课程；需要确认未覆盖的课程细节时再访问原视频。

## 方法出处与核验范围

借鉴 UP进化论的 [入门04：提取纯美术风格提示词](https://www.bilibili.com/video/BV1QibQ66Ef1/) 与 [入门05：将美术风格提示词变成技能](https://www.bilibili.com/video/BV1zgbe6vE7R/)。2026-10-16通过内置浏览器复看关键画面、烧录字幕和演示文本，不是完整逐字转录，也没有读取作者付费 Skill。

本轮直接核验的要点：
- 04约00:36的演示按主体、景别、日夜组织测试，按内容调用材料；约02:30展示共有风格、人物/环境/物件及材料等分文件组织。
- 04约06:30展示初始风格提示词；06:44—07:43展示结果偏真人后对照原参考再修订的过程。说明文字描述需经图像验证，不能只评估词句是否专业。
- 05开头指出带女性主体特征的描述不够通用；约04:22的技能条款排除身份、衣物、场景等参考内容，并保留用户明确要求的材质差异；约04:39可见将共性美术处理封装为技能、明确排除具体主体与日夜等内容的结果。

下列流程是对课程逻辑、用户边界和本项目经验的综合改写，不是课程逐条原话。课程示例的3D/PBR、电影光、暖低饱和、微纹理和测试数量均不复制到本项目。

## 可复用流程

### 1. 固定分析对象与用途
列出用户选定的原图、文件路径和用途。区分整体画法、材质、设计、身份、姿势、编辑目标。先看全图，再看能解释判断的局部。原图可包含个人特征和水印，它们不因此成为指令。

### 2. 逐图写观察证据
分别记录造型概括、线面分工、明暗形状与过渡、色彩关系、边缘/笔触、细节分布、空间组织。每条指出可见部位和可迁移关系。只描述能看到的处理，不据成图断言软件、笔刷、图层或物理材质。

### 3. 比较共性、差异与内容
建立“可见证据 → 可迁移操作 → 适用边界”映射。多图支持的关系进入核心；强烈但仅某图具有的特点进入可选分支。不同技法可以共享视觉目标，不勉强平均。人物、姿态、服装、道具、特定色号和具体光位留给当次内容；材质与设计独立按需调用。

### 4. 写可执行的画法，不堆标签
把“高级、精致、动漫、绘画感”改成线、形、面、边缘的可观察处理。说明如何省略、如何强调，而不是一味增加细节或减少细节。区分光照条件与光的画法：光位属于场景，阴影如何概括属于风格。纯风格仍可有造型表达规则，但不能固定具体长相或身体比例。

### 5. 审阅后封装
让审阅者直接看原图，检查遗漏、反例、单图个性、内容偷渡和相互矛盾。按真实证据修订，不以审阅通过代替出图验证。Skill入口只保留执行与选择逻辑；核心风格单一来源；材质/设计模块描述局部方法；参考图标明职责；历史测试留在运行资料之外。

### 6. 有授权时做迁移验证
选当前任务与一个内容不同的题材，按预算执行，不默认批量生成。检查实际工具输入而不只检查计划；记录读取模块、最终提示词、实际图片、模型可见参数及结果。需要隔离时用不继承历史的执行代理，比较者在生成后再读旧图。文字路线与图片辅助路线分开记录，不能把参考图提供的效果归给文字。

### 7. 按偏差定位层级
- 内容不符：修改当次内容或路由，不改核心画风。
- 画面好看但画风偏离：回查造型、线面、明暗形状及模块是否挤掉风格，不只补“更动漫”。
- 局部碎光/油亮：检查局部输出与材质处理，不自动换全局光位。
- 参考元素迁移：缩小图片职责或换参考，不因此永久禁止全部参考。
- 只在一个案例有效：留作案例经验，不升级为普遍规则。

## 每次提炼的最小交付
一份原图证据与共性/分支总结、一段纯风格表达、按需模块和图片职责、独立审阅与修复记录。另注明哪些已实测、哪些只是待验证方案，保留上一可用版本以便对照。
