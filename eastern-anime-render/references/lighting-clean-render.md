# 当次场景的照明一致性

核心风格规定明暗的绘画处理，本文件只辅助本次光照方案；不固定光向、色温或时间。

## 组织光照

先确定当前构图和体块朝向。按用户场景选择光源方向、范围、软硬及环境补光；具体方案依据本次创作需求决定，不从历史案例继承固定光位或色温。多光源可以使用，但各光源需有可解释的来源与作用区域。

提示词只补充足以消除歧义的信息：光源 → 主要受光/背光关系 → 当前可见的遮挡关系。超柔光、平面装饰或极简画面不强造投影；不要求固定数量的阴影说明。改姿势后重新判断朝向，不沿用旧图每块亮斑。

所有材质共享场景光源，但反射形态可以不同。不能要求不同表面的高光处于同一侧或同一高度，也不能跨不同固有色机械比较明度。检查同材质内部的亮暗与遮挡是否合理，及反光能否由当前环境解释。

颜色词不自动产生光源。珠白、灰紫等仅控制配色，除非明确要求，不追加自发光、全轮廓亮边或独立材质灯。具体材质响应见 [材质参考](materials.md)。

## 检查

生成前检查内容、风格、材质段是否暗含互相冲突的光位；实际工具提示词需表达已选择的关键关系。生成后先缩小看整体明暗，再检查各主要体块及可见投影，最后检查局部高光。若必须额外假设多盏未设定的灯才能解释，记录为待修正；高光位置不同本身不算失败。无法确认的关系应注明不确定，不虚构精确光源重建。

依据：[Proko 光与体积](https://www.proko.com/course-lesson/shading-light-and-form-basics/)、[PBRT 毛发散射](https://pbr-book.org/4ed/Reflection_Models/Scattering_from_Hair)。这里只借助绘画层面的关系判断，不把物理渲染参数塞入风格词。规则仍需新构图验证，不保证模型永不出现噪点或光照冲突。

参考6中的装饰性色层、断续色边和干刷是画面组织，不自动成为独立灯光或表面凹凸。判断光照冲突时区分真实受光/投影与绘画色层，不要求每一笔装饰色都能由物理反射解释；也不用装饰色掩盖互相矛盾的实际投影。已认可宏观照明保留。
