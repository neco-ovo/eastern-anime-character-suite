# 服装设计：丰富但有主次

依据用户的10张服装设计素材及服装材质图。古风1/2提供内外层与装饰分区，3/4/5提供薄层与纹样节奏，6提供强反光对照，7/8提供长袍与不对称组织，礼裙/礼裙2提供垂褶、边饰与点色。这里提炼设计关系，不复制整套款式，也不将幻想设计当作历史服制证据。

## 调用条件

用户要求服装设计、角色细节或允许创作且未指定完整衣着时，主动完成与角色相称的设计。普通生图不必默认无纹样素袍。已有明确服装、极简要求、制服或历史制式时，保持其约束；不能因为库中多为礼服就擅自升级成华服。

## 从轮廓到细节

1. **轮廓与用途**：按动作和角色安排合体/宽松、长度、开合和袖型。主体轮廓先有辨识度，配件不能阻碍动作。
2. **叠层与分区**：用内外层、领襟、腰部、袖口或下摆的关系建立层次。不是每个位置都必须增加一层；结构线既解释穿着，也划分大色面。
3. **材质对比**：在实际设计部位选择对比，例如主要布面与较挺包边、软衣料与小面积金属扣。对比来自真实部位，不能同一片布同时要求厚重毛料、透明纱和镜面缎光。
4. **纹样和装饰**：选与本次人物相称的主题或几何规律，安排主要装饰区域与次级呼应。不同部位可分别用裁片叠层、刺绣、包边、系带或首饰体现设计，把这种分工写进当次提示词，避免将多个部位并列描述成同样精细醒目的珠宝组合。纹样在重点部位聚集、延伸或重复，留出连续布面，并随裁片、褶面和遮挡变化。华丽程度及装饰数量按角色与用户意图选择。
5. **配色与细节尺度**：主色承担大面积，辅色区分层次，点色强调关键部位。实际色相按任务选择；远景优先读轮廓和分区，近景再展示局部工艺，不能靠全身微纹理让衣服“精细”。

## 可选设计复杂度

| 当前需要 | 可选手段 | 避免的误解 |
|---|---|---|
| 日常、朴素、利落 | 裁片比例、领口层次、系带或扣合、窄包边、局部同色纹理 | 朴素不等于无结构，也不自动添加首饰 |
| 有辨识度的角色服 | 一个统一设计母题、局部不对称、内外层对比、重点部位纹样 | 不必强制一个纹样或固定饰品数量，按人物需求增减 |
| 华丽、仪式或贵族主题 | 更复杂叠层、较精细边饰、局部刺绣/珠宝、疏密对比 | 华丽不等于每块面同密度、每条边发金光 |
| 明确指定极简或特定制式 | 在允许范围内处理版型、接缝和表面 | 不用本库替用户改款；历史准确性另需可靠资料 |

文字组合示例，不是固定方案：“以【轮廓/主衣层】建立主体，【主要装饰区域】用【选定工艺或配件】形成重点，【呼应部位】通过【裁片、纹样或织物结构】延续设计，其余布面以垂坠和叠层衔接；不同材料各自表现光泽。”仅保留实际选择的部分，不把占位符传给生图。

## 图片何时有价值

按当前袖型、叠层穿法与图案节奏主动查看对应原图，以文字设计方法与图片关系共同约束；不以难以描述为前提。只提取所需关系，不继承整套服装、植物主题、色号、身体比例或教程版式。图中薄层感可以启发设计，但不是对纤维成分的确认。

核对：衣服是否适配角色和动作；大轮廓、层次与重点能否读清；装饰是否有分布逻辑；丰富度是否来自设计而非碎光。首饰需要时读 [配饰](accessories.md)，表面处理读 [衣料](cloth.md)。
