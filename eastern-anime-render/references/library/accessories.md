# 首饰、发饰与佩件：设计和反射分开

来源等级：OIP产品广告卡的贵金属/精密结构原则为已读文字；原组0的珠饰局部及本地服装设计图为已有视觉依据；下面的古风角色组织方法为改写与综合，不是OIP原文模板。详细来源和限制见 [依据](sources.md)。

## 设计方法

先决定配件为何出现：固定头发、闭合衣服、承接腰带、表达身份或提供视觉重点。再安排主形状、连接与附属件。发簪、耳坠、项饰、腰佩等是可选类型，不是每个角色都要全套。

- 主件与次件共享曲线、几何或纹样语言，尺寸和密度有层级；与[服装分区](costume-design.md)共同安排视觉重点，呼应可通过衣料纹样或结构完成，不必在每个部位重复整套挂件。材质段描述已经选定的配件，不因需要展示金属、宝石或流苏的质感另添饰品；主饰位置和数量由当次设计决定。
- 链条、扣环、镶托和衣物固定点要能解释悬挂；垂坠随重力与动作变化，不能在脸或衣料上悬浮。
- 首饰的面积、亮度及细部描述按可见尺度与本次设计重点分配；作为服饰局部也可精密，不要求首饰必须是主体。工艺细节服务于画面层级，不自动将整幅画变成微距摄影。

## 材质分支与绘画转译

| 表面选择 | 可用处理方式 | 不自动附加 |
|---|---|---|
| 抛光金属 | 先读薄厚与转折，再以少量明确亮暗变化标示反射；连接和镶托保持形状 | 全轮廓金边、发光、每处同样耀眼 |
| 较柔的金属表面 | 较宽柔反光与局部清楚边缘相配，保留结构 | 全面微划痕或摄影噪点 |
| 切面宝石 | 把色面与明暗分组到主要切面，镶托与石体分开 | 每个切面都白亮、无来源自发光 |
| 珠状或温润石质饰件 | 用圆转体积、克制反光和少量色层区别于金属 | 将珠白配色当作珍珠材质、把所有玉石画成透明玻璃 |
| 编绳、流苏、细链 | 先建立悬挂方向与主要束组，末端少量分离，按需要保留节点 | 全部铺成等粗等亮细线、无连接的装饰 |

前两项和宝石的“材质区别、反射克制、结构连接”借鉴OIP文字原则；珠状、绳穗为本地原组观察与绘画改写，非新增OIP图像提取。指定真实宝石品种或工艺时，不能用这张概括卡代替专门资料。

可用表达：“【选定配件】以清楚的主件与连接形成设计重点，次级部件顺着悬挂方向组织；金属、石体与绳穗分别呈现反射，精细处集中于可见焦点，服装与皮肤仍服从原有大明暗。”不需要配饰就不调用此段。

## 可选视觉依据

已有 [珠饰局部](../images/jewelry-response-original.png) 来自原组0，混有织物，仅辅助材质差异；具体繁复形状可看相关服装设计原图。精细镶嵌或特定工艺无法靠文字稳定表达时再检索图片，实际查看后记录来源。未核验OIP案例图不作为可用图片传入。

本模块没有经过独立生图验证，不承诺精密结构一定生成正确。检查配件连接、材质区分、轮廓清晰度以及是否抢走人物焦点。
