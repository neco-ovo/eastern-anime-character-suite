# 补充表面：自然物、毛皮和道具

只用于当前画面已经需要的对象，不因为模块可用就新增宠物、家具、植物或食物。以下区分已有视觉提炼与尚待验证的绘画建议；不是新建的完整材质图像库。

## 已有局部视觉依据

- **宽叶面**：原组5的莲叶，主叶面用较少色块说明转折，叶缘和局部脉络帮助读形；不把厚宽莲叶的方法直接等同于所有叶种。可选 [叶片局部](../images/leaf-plane-original.png)。
- **池景水色**：原组5的池水语境，用深浅块和选择性留白组织倒影、植物与水的关系。参考混有植物，只支持池景概括，不证明海浪、折射或透明水滴。可选 [池景局部](../images/water-context-original.png)。
- **薄层衣料与叠色**：服装设计3/4/5可观察叠层后的底色变化和边缘，适合说明穿叠设计；渲染时保持衣层分离，不把薄纱选择扩散到所有衣服，也不据图断言真实纤维。

## 文字补充方法，尚无专项素材验证

| 对象 | 可迁移的绘画建议 | 核对 |
|---|---|---|
| 毛皮、动物绒毛 | 先画有厚度的毛团与生长方向，细毛集中在轮廓、分缝和受压处，内部保留连贯体积 | 区分活体与衬垫的结构、接触和轮廓；不能平均撒白线或照搬头发反光 |
| 木与漆面 | 按当次设计选择裸木、涂饰及使用状态；木的纵向纹理、端面与接合说明构件，漆面则通过覆盖的底色与反光表现。以细线、顺势宽擦和薄层穿插组织这些差别 | 绘画露底指画面底色透出；剥漆、裂纹及磨损是物件状态，按当次设计另作选择 |
| 石、瓦与抹灰面 | 石块以分块、接触与局部石理读厚度，瓦以弧面、叠压与坡面色群读层次，抹灰面以连贯色域和选定的擦痕表达墙面；各自用核心画法组织边缘与叠色 | 纹理尺度随部件和观看距离变化，清晰度按用途安排；不是整面统一铺同一种磨蚀图案 |
| 陶与釉面 | 陶体用器形、口沿厚度和表面转色建立体积；有釉的区域以成形光斑及其边缘区别于胎体，笔触与色层接入相应转面 | 是否施釉、装饰及新旧程度由本次选材决定；颜色变化不自动增加釉裂或彩绘 |
| 果肉、果皮与湿润小物 | 先保持对象轮廓与接触，湿润反射局限在对应表面，内部色层服务于体积 | 果肉、金属和皮肤的亮部职责不同；湿润不扩散成全场油膜 |

毛皮方法是本地绘画综合建议；OIP毛绒生物案例只提供“毛皮与柔背景分开描述”的文字语境，未看该例原图，不为细毛组织提供已验证证据。既有道具与食物方法借OIP受控反射和局部材质层级作抽象，再适配动漫绘画；来源见 [依据](sources.md)。本轮木、石、瓦、抹灰与陶釉的细分是结合杂货铺测试提出的综合画法建议，不宣称来自新增OIP素材或已经生成验证。不照搬摄影、微距、黏土或商业海报画风。

当新对象的主要材质难以确认或文字无法表达所需差异时，再查专门案例；将新观察补入对应类别，保留来源和不确定性，不据一次成图推广到所有动物、植物或食物。
