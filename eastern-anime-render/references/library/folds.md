# 衣褶：由受力组织形状

本模块属于结构方法，不是固定服装或高光模板。依据本地服装褶皱1—9：1/3提供弯折与堆积，6/9提供支点与悬垂，8提供包裹与收束，7提供大面组织；2/4/5的上色另见 [衣料](cloth.md)。小字未完整转录，以下为对图形的归纳。

## 方法与分支

| 条件 | 组织方式 | 绘画表达 |
|---|---|---|
| 自由下垂 | 从承托或固定处向下组织主褶，长短与间隔有主次 | 长面之间留连续色面，靠交叠和转折读重量 |
| 两侧牵引、兜布 | 支点之间形成弧形垂坠，弧线随深浅分层 | 弧线不是等距描边；深处与覆盖处才需要明确暗部 |
| 弯肘、屈膝、袖口堆积 | 压缩侧容纳较密折叠，拉伸侧相对展开 | 密度集中在受力区域，不平均铺满衣身 |
| 包裹和束腰 | 褶向受束位置汇合，再沿包裹体积变化 | 转折跟随身体体块，衣料仍有自己的厚度和余量 |
| 接触座椅、地面或手 | 接触处压扁或堆积，离开接触后恢复悬垂 | 接触阴影区分层次，不用一整圈黑线圈出 |

顺序：读身体与支点 → 主褶与连续面 → 局部压褶 → 根据当次光照上色。姿势改变后重建受力，不能挪用旧图同一组折线。

可用表达：“衣料从支点展开主要褶面，压缩与接触处才聚集短褶，拉伸侧保留较大的连续面；交叠有厚度，明暗随本次光照。”只选本次实际发生的关系。

## 何时看图

按当前支点、拉伸、压缩与垂坠关系查看相符原图并选择相关区域，常见衣褶也可用图约束；特殊兜布、缠绕与多个支点同样按结构匹配。结构图只帮助判断受力，不提供最终材质、灰阶配色、人物比例或衣服款式。所有原路径见 [清单](manifest.json)。

检查：褶皱能否解释支撑和动作；大面是否仍连续；褶脊是否被误当成等亮高光；是否用更多微褶冒充细节。

默认保留有受力依据的主褶与垂坠，次级折叠只需足以说明压缩和叠层；不为增加精细度遍布短折或尖角小面。褶皱密度随衣料和设计变化。参考6的绘画擦痕与异色色层不作为褶皱结构证据。
