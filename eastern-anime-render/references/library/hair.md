# 头发：画法与表面参考

本卡不指定发色、长度、发型、性别或动作。反射服从当次光照；黑发不机械复制浅发的亮度。

## 不依赖传图的提炼方法

来源：头发1/5/7提供渲染分支，2/3/4/8提供分束、动态和概括方法。下面是对可见形状的归纳，不是教程小字逐字转录。

1. **体积组织**：先读头部上方的发量，再分承接发根方向的主要发束；通过前后叠压、束间空隙和转向区分发束，不靠等密度细线分割整片头发。
2. **线与面**：外轮廓和遮挡交界可以明确；面内细线随局部色彩降低对比。不要每束都描一圈亮边，也不为“干净”抹掉所有细丝。
3. **颜色与反射**：反光按束面方向成组，随弯曲改变宽度与边缘。暗部保留固有色和环境色联系；金发样本的亮度不能直接套给黑发。
4. **动态与造型**：弯束有主弧线和次级分叉，细丝在少量区域打破规整。编发先明确交替穿插和遮挡，光泽再服从这些体块；不是靠锐亮碎面证明编织。
5. **选择分支**：线面型H1强调有色轮廓与较明确的带状面；柔绘型H7强调较弱线与圆转过渡；头发5/6的硬面或强光泽只有当前需要时采用。分支影响头发表现，不要求改变整幅风格。

简洁表达示例：“主发束先建立连续体积，交叠处明确，内部细分顺着转向且低于主明暗对比；反光随曲面成组，局部细丝打破轮廓。”发型与光泽强度另按任务说明。

依据当前发束组织、线面节奏与光泽目标选用相符图片，普通长发也可从中受益；不因文字能描述而省略。多个参考有互补作用时可一起选，数量取舍遵循 [分类库](index.md)。

## H1：有色线与带状色面

- 来源：`头发画法素材/头发1.jpg` 下半棕发；[原像素局部](images/hair-line-plane.png)。
- 观察：轮廓线与内部色线有轻重；较大带状发束交叠，暖色亮面与偏灰紫暗面分开，细丝留在局部。原图也有碎亮片，并非纯净无高光样板。
- 可用描述：发束先形成有厚度的带状大面，有色线条提示交叠和少量细丝；面内明暗沿弯曲连续变化，细节集中在转折与交叠处。
- 适用：需要保留较明确线稿的动漫绘画。只借线面层级；暖亮冷暗为该图观察，不是全场景固定配色。

## H7：连续曲面的柔绘光泽

- 来源：`头发画法素材/头发7.jpg` 左侧完成稿；[原像素局部](images/hair-soft-volume.png)。
- 观察：大束先成体积，宽柔反光跨越曲面，内部细线对比低于主明暗；局部仍有亮丝。比 H1 弱线、更柔滑。
- 可用描述：以连续发束体积和较宽的柔和反光描述弯曲，内部细分顺着生长与转向展开，保持暗面厚度和少量清晰交叠边。
- 图片限制：裁切仍含教学色球、色样及白底版式，只参考头发的曲面与反光关系，不迁移这些教学元素。
- 适用：柔绘头发；不把整幅画变成光滑塑料，不把卷束形状、金发或偏上方的反射位置当成模板。
