# 光照示意：只参考明暗组织

原图：`E:/AIGC/ref/二次元绘画素材/光影素材/下载.png`、`光影2.jpg`。

两张都是多方案灰阶示意，优点是大明暗分组清楚，缺少连续调子和精细材质证据。它们不能证明一套彩色配光，也不能充当“柔光、去油亮”表面样板。

## 使用

文字提炼的工作顺序：先按当次场景选择光源及环境补光，再确定哪些大面朝向光源，最后处理发束、衣物、配件的遮挡。把主体明暗先分成可读的大组，面内细分服从主关系；投影边缘和材质高光分别判断，不能都用一种硬度。

两张灰阶示意支持“同一形体换光向会改变明暗分区”的观察，不支持固定光位、色温、单光源数量或所有场景都柔光。保留用户选择的硬光、多光源或装饰性处理，只要求画面关系可读。

柔和转面与大光源柔光是不同选择：前者是绘画处理，后者是当次布光。去碎面首先检查面内组织，不自动重布光。相符的明暗示意可与文字共同约束；选择当前光向与体块关系相符的区域，避免多格光向相互冲突，数量按分类库规则取舍。

当本次需要确定或解释光向时，实际查看原图，选择与当前头部朝向、场景匹配的一格。提取受光覆盖范围、背光大块、刘海/鼻部/配件遮挡关系，按当前形体重建。无需改变当前打光时不加载这些图。

- 下载.png：不同方向的头部明暗与轮廓光；不能一次叠用上光、侧光、逆光的小格。
- 光影2.jpg：同一人物及花朵等遮挡下的不同明暗分区；只借分区逻辑，不移植花束、人物或服装。

可用描述：本次光源先形成可读的大受光与背光区域，投影随遮挡物与形体朝向组织；局部颜色、反射与过渡由已选风格和材质决定。

与 `../lighting-clean-render.md` 配合。具体左/右/上方光、曝光、色温及明暗比例都属于当次方案，不能因此成为 Skill 默认值。灰阶教学中的硬分界不要求转成最终全图赛璐璐。
