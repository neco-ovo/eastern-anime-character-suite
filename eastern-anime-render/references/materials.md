# 按需材质参考

材质回答特定表面如何表现。它不定义整个画风，也不决定画面必须有什么。只加载本次出现且需要细化的项目；无相应内容时不调用。所有反射服从当次场景照明。

用户新增的49张混合素材已提炼为 [分类画法与设计库](library/index.md)。文字方法与相关图片共同约束，按分类库规则先选有用图片、超限再取舍；强光泽皮革、柔亮布与哑光厚布感分别适用。结构、设计和光向独立调用。局部图的来源、坐标与知识模块映射见 [清单](library/manifest.json)。已有若干参考组合试图，但文字模块的稳定效果尚未验证，不能宣称已解决去脏。

## 使用与去噪

先写用户指定的实际材质，再借裁切中的绘制方式。未指定材质时不因看到反光就断言丝绸、金属或特定宝石。示例：“本次头发采用连续发束和低对比内部细分，反光随已定光源及曲面变化。”不能附带原图发色、人物或光位。

若头发出现脏感，先检查随机亮碎片、交叉短线及等密度小切面，保留大束内部的低对比变化和少量必要细丝；不靠纯黑填平、磨糊或全轮廓发光解决。织物的细节来自褶面、叠层与选定纹理，不靠每条折脊同亮的细线堆积。湿润、刺绣等具体材料或设计属性按当前内容决定；核心6已选择的绘画擦痕与肌理属于画法，不以题材是否需要颗粒作为启用门槛。它们可充分存在，但不自动成为布面凹凸或油膜反射。

材质不足时可从用户参考或 [OIP](oip-integration.md) 补充：实际看图 → 确认具体表面与上下文 → 原像素裁切或记录局部 → 写清来源、范围与不确定性。不要把重新生成的示意图称为原图提取。新的叶片、池水和珠饰裁切尚未经过生图回归。

裁切坐标见 [参考映射](reference-map.md)，新增裁切的机器可读来源见 [记录](material-crops.json)。
