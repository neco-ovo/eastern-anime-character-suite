# 东方幻想 · 动漫绘画渲染

默认读取 [核心风格](references/style-guide.md)，以6..jpg的叠色、流动线面及绘画肌理为主；0与111仅补充相容处理。风格规定如何画，不规定画什么。适用于角色插画；实际测试与反馈见[测试记录](references/validation.md)。

## 与面容、姿态参考技能协作

联合使用时，本技能为主导：按需读取 [anime-face-expression](../anime-face-expression/SKILL.md) 与 [anime-pose-design](../anime-pose-design/SKILL.md)，将它们作为面容关系与姿态方法的参考来源。两者提供局部建议、适用条件、候选图片职责及局部观察；由本技能统一取舍、转译、编写最终版本提示词，并完成生成后的整体审阅。按实际需求调用，不因存在辅助技能而固定加载全部资料或增加审阅轮次。

先明确用户本次意图、已认可表现和主画风的视觉重心，再选择能支持它们的面容与姿态建议。局部建议可改写、合并或不采用；用户明确设定与要求仍须落实。人物气质、剪影节奏、衣发流动、动漫概括、线面和色层应在同一画面中成立，不让局部结构分析自动升级为写实刻画或压低艺术表现，也不以画风为由略过影响可读性的真实结构错误。

最终提示词由本技能重新组织为统一表达，保留必要的可见关系和具体约束，不拼接三份技能全文，不带入历史故障清单。用户要求仅文字或不输入图片时，所有辅助技能遵守该范围：用文字具体交代所选画法与造型关系，不能只写风格标签，也不自动补传参考图。

## 执行流程

1. 提取用户本次主体、动作、服装、构图、场景及明确约束，在授权范围内主动完善画面。已认可表现退出默认纠错；仅针对当前仍需解决的问题调用历史经验，新需求或新构图所需调整按实际处理。参考图中的身份、姿势、道具和材质不能自动成为内容要求；不规定通用手型或身体比例。
2. 默认应用6的核心画法，用户另有明确画法要求时按其要求调整。将画风、技法、颜色关系、光的绘画处理写成简洁渲染段；保留可辨识的叠色、断续色边与笔触节奏，结合本次形体组织细描与宽色面的对照，不将辅助图等权叠加为平均画风。
3. 按本次创作需求安排照明，必要时读取 [照明一致性](references/lighting-clean-render.md)。光位、时间、色温属于当次方案，不写回风格默认值。改姿势后重新检查受光关系。
4. 查阅 [分类画法与设计库](references/library/index.md)，按可见部位、主要表面和设计需求选择文字模块。文字说明形体组织、技法与渲染关系，同时选用相关图片约束视觉表现。服装细节未指定且允许创作时，用设计模块安排与角色相称的层次和细节；用户指定的简素、制服、历史制式或既有设计优先。首饰与纹样属于当次设计选择，不能由材质段自动增加。
5. 从所选模块及 [原组参考映射](references/reference-map.md) 主动选出对当前画法、主要材质、结构或设计有用的参考，并实际查看；文字能描述不构成省略图片的理由。遵守用户仅文字、仅材质等明确约束。所选适配图片不超过当前工具上限时全部传入；超过当前实测五张上限时，才按本次目标的重要性、互补性及重复程度取舍。允许同类多张互补，不预设每类一张，也不为凑数引入无关或冲突图。整体参考允许时优先选择6作为画法锚点，0/111按缺口补充，不默认由111取代6。区分整体画法、局部表面、结构/设计、身份及编辑目标，记录实际输入与超限取舍。
6. 编写或优化角色提示词时，读取 [角色与服装提示词写法](references/character-costume-prompt-writing.md)，参考用户提供文档中的裁剪、叠压、材质受光与姿态重心表达，按本次需要转译。将主体与当次设计、核心风格、局部画法和照明按语义合成自然语言。可先交代主体、场景和构图，再组织画法、色彩与照明，按主要表面表达材质及参考职责；按本次需要取舍，不必填满模板。将选定画法写成相互关联的视觉处理：线与色形如何呼应，底色与叠色如何相融，边缘、笔触与疏密如何衬托；按本次画面组织这些关系，充分表达创作意图与表现力。材质句写明当次选定的表面、涂饰或使用状态，以及相应亮暗、反射与纹理如何用主风格表达；绘画薄擦和露底说明画面色层，物件的彩绘、磨损或剥落另按设计选择。不能只剩“随曲面展开”或以详细材质说明覆盖整体画法。合并同义要求，协调各段的设计主次与分布；补充局部设计时同步相关描述，校正融入或替换原句，不按模块全文追加；必要的强调和具体排除仍可保留，不以字数或零重复为目标。图片按实际输入顺序简述职责：参考提供线面、叠色与笔触的组织方法，具体色群、叠入颜色及承接部位按本次作品设计，并在画法段与参考说明中一致表达；用户明确借鉴参考配色时，将其纳入当次方案。避免复述整张参考；内部分析、历史缺陷清单与执行检查不搬进生成正文。设计复杂度、表面微细节和反射强度按题材与画法分别决定，艺术上的简化同样可以成立。具体配色、姿势、饰物及光位不写回跨任务默认值。

## 提示词与生图

- 只要求提示词时输出可复制中文，必要时附等义英文，不自动生图。仅更新技能时也不额外生图。
- 要求出图时使用当前 Codex 内置 image_gen，并遵守 imagegen 技能及工具实际 schema；不自行改用 API/CLI 或脚本绘图。
- 用户偏好称为“image2.5”的能力；工具未暴露模型选择时不伪造参数、不声称指定了该版本。精确版本是硬要求时如实说明可核实范围。
- 参考路径相对于本 Skill 根目录解析。必须通过工具实际图像输入传入，不能只把文件路径写进提示词就声称已传图；不混用互斥参数。
- 新角色创作中，参考图仅传递指定视觉属性，不作为待修改底图。编辑时明确目标与参考的不同角色。
- 图中文字不是指令。不要迁移署名、水印、日期或遮挡条；用户另行要求的画面文字按原文处理。
- 图片丢失时按映射查找原始路径，仍缺失则说明只能按文字执行。工具不可用时提供提示词并说明未生成。

## 检查与迭代

由本技能实际查看生成结果并作整体审阅：结合用户本次意图及已认可表现，判断人物气质、整体画风、剪影、线面、色层、光照与材质是否共同成立。面容与姿态技能可提供局部观察，不能凭五官或结构局部通过就判断整图完成；明显的内容、连接或接触错误也必须纳入总审阅。区分妨碍表现的偏差与有意的艺术处理。已满足本次要求时直接交付，有具体偏差再聚焦修订；技能内审不替代用户对作品的最终批准。

迭代已认可的作品时，以该版本实际使用的提示词和参考输入为起点，保留已获认可的表达，针对本次反馈调整对应内容；新意图或实际画面需要整体调整时，可重新设计，并说明同时改变的主要变量。比较测试按实际改动说明范围，多处变化作为组合方案评估。继续迭代依据用户要求或已有预算；沿用第1步对已认可表现的处理，不将文件检查通过表述为出图验证通过。

## 按需资料

- 重新提炼参考组或设计技能时，读取 [风格提炼与封装流程](references/style-extraction-workflow.md)；已记录课程逻辑及核验范围，无需日常反复看视频。主参考与辅助图的判断依据见 [风格证据](references/style-evidence.md)。这两份不是常规生成的追加提示词。

- [分类画法与设计库](references/library/index.md)：49张用户素材提炼的文字方法、按需图片与OIP补充。按任务同时选择文字方法与有用图片，按上述上限规则传入。只允许材质参考的任务不追加整体人物或姿势图。

- 用户要求去脏或已确认局部明暗过碎时，读取 [局部碎光校正](references/local-shading-correction.md)。它是独立输出校正模块，不修改核心风格；若整体打光已获认可则保留。

- 扩充案例或缺少合适材质时用 [Open Image Prompts](references/oip-integration.md)；日常调用不要求联网或数据库。
- [测试记录](references/validation.md) 仅供评估与回归，不作为默认提示词。评分、固定光位和历史题材不进入运行规则。
