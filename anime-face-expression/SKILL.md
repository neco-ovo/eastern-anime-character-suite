# 动漫面容与神态

提供脸型、五官关系与神态的局部参考，供当次主画风技能选择和转译。与 eastern-anime-render 合用时，由它主导整体风格、最终提示词与成图总审阅；本技能不独立定稿、发起生图或作最终通过判断。单独调用时交付面容参考建议，不据此新增图稿；用户选择其他主画风时由该画风承担整合职责。本技能不规定统一脸、年龄、性别表现、眼形、瞳色或光泽。

## 使用方法

1. 根据用户本次表达目标选择有助于面容设计的信息，来源可以是角色设定、参考图、现有面容或直接文字要求，资料范围按任务需要确定。背景、性格或意象仅在能支持具体视觉选择时使用，不为解释气质补写未经要求的心理或情境。分清已定外貌、可设计部分、当下表情和头部视角。迭代时保留已认可的长相及画法，定位当前需改的关系，不为改表情自动换脸。
2. 读取[面容方法与参考](references/facial-features.md)中本次需要的部分。先在完整头部上组织颊颌轮廓、五官位置和近远侧关系，再协调眉形、眼睑开合、虹膜遮挡、视线落点、唇缝与嘴角。气质词保留为意图，同时写出能表达它的可见关系。分开判断形貌特征、年龄感、当下神态与表面画法，针对本次目标选择需要调整的关系，说明组合后的表达。避免建议只剩“自然、平静、柔和”等通用协调词，或只有排除项而没有所需神态的正面设计。
3. 用户允许图像参考时，按当前角度、神态与画法选图并实际查看。混合表情页先读全图，再选相关小格；必要时使用保留来源记录的原像素局部，不补画、不迁移拼图版式。图片分别标明结构、神态或局部画法职责；图片中的人物身份、发型、配色与装饰只在用户需要时借用。
4. 将本次表达目标、所选可见关系、需维持的既有特征，以及适用条件与可能冲突一同交给主画风技能取舍并融入最终提示词。分析依据不搬入生成正文，局部建议不必重写整张脸，也不交一段要求原样追加的最终生成指令。仅文字任务用文字方法提供参考，用户仅文字、仅局部等约束优先。候选图片及职责也交给主画风技能统一选择和记录，读取或写出路径不等于传图。
5. 主画风技能需要局部审阅时，按实际画幅提供年龄、面部同一性、视线与眉嘴协调的观察，区分可见偏差与艺术概括；由主画风技能综合判断并修订，不以局部检查通过代替整体成立。已有面部局部可辅助观察，不因此新增图稿。全身图的面部像素有限，不承诺微表情必然呈现。

## 与画风技能配合

使用 eastern-anime-render 时，将局部建议交回其[入口](../eastern-anime-render/SKILL.md)，由它统一决定面容的动漫概括、线面、叠色、笔触与整体层级，并完成最终提示词及成图审阅。皮肤和眼部表面处理按需读取其[皮肤与眼部](../eastern-anime-render/references/library/skin-eyes.md)。面容建议可被改写、取舍或不采用，不另立画风，也不将结构线稿的质感当作成图要求；用户明确设定仍须保留。

## 选择与修订

- 眼睛与嘴部分别看似合适，组合后仍可能表达不同情绪；放回完整脸判断，结合视线和头部姿态。
- 细长眼、半闭眼、少高光或平嘴角都不能单独等同某种性格。温柔、清冷、疲惫或倨傲应按当次角色整体表达。
- 可爱感、成熟感与年龄不是同一轴；修订气质时不自动拉长脸、缩小眼睛或增加妆感。
- 细节与光泽按当前目标保留；不把一次去甜美、去油亮或某角色的修订变成所有人物的默认。
